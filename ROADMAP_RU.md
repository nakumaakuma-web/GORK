# Prompt Extractor Studio — техническая дорожная карта

## Цель
Локальная программа обратного промптинга: готовые фото и видео → подробный визуальный паспорт → Positive/Negative RU/EN → подготовка для CyberIllustrious V4 / FramePack → последующая проверяемая генерация.

Восстановить исходные промпты автора дословно по файлу нельзя; Negative Prompt составляется заново.

## Реализовано до v0.5
- Qwen3.5 35B через llama.cpp, фото и выборка кадров видео.
- Отдельные положительные и отрицательные промпты RU и EN.
- Проверка правильности языка, базовая сверка левой/правой стороны, визуальная проверка в максимальном режиме.
- Обновления из GitHub; модели GGUF и личные файлы не изменяются.
- В v0.5: единая версия, три режима скорости, остановка между запросами к Qwen, промежуточные черновики, RAM-кэш повторных анализов и защита от двух параллельных задач.

## Следующие этапы (не заявлять готовыми до реальных проверок)

### 0.6 — структурированные факты и точность
- Канонический JSON-паспорт: внешность, анатомия, поза, стороны тела, одежда, аксессуары, освещение, стиль, видимые детали, неопределённости.
- Одна база фактов для русских и английских промптов; контроль consistency.
- Обнаружение неполных ответов и избирательный повтор только пропущенных полей.
- Перевод терминов: sheer / fishnet; light / focus; левая/правая сторона.
- Экспорт шаблонов под Illustrious и FramePack без подмены смысла.

### 0.7 — коллажи и точечная проверка
- Автоматическое определение коллажей, отдельные панели.
- Выделение области (ROI), анализ фрагментов с сохранением связи с основным кадром.
- Контроль ключевых признаков внешности; ручное редактирование сохранённых полей.
- Без автоматического приписывания скрытых/недоказанных деталей.

### 0.8 — видео
- Адаптивный выбор ключевых кадров, учёт времени и смены ракурса.
- Встроенный таймлайн движений и промпт камеры; отдельная карточка внешности персонажа.
- Опциональный FFmpeg при отсутствии поддержки кодеков браузером; без дублирования установленного софта.
- Реальные испытания на коротких видео 5–10 секунд; проверка положения рук, ног, объектов и траектории камеры.

### 0.9 — генерация изображений
- Проверка локального движка Illustrious/SDXL и CyberIllustrious V4.
- Отдельный безопасный адаптер генерации, без ComfyUI или Stability Matrix.
- Создание фото по позитивному/негативному промптам, сохранение seed и параметров.
- Сопоставление результата с референсом по чертам лица, пропорциям, материалам, стилю и позе.

### 1.0 — FramePack и качество
- Определение конкретной установленной версии FramePack и наличия поддерживаемой LoRA.
- Передача исходного кадра + короткого Motion Prompt, управление последовательными заданиями из одного интерфейса.
- Не обещать поддержку Negative Prompt в версиях, где поле игнорируется.
- Переключение между анализом Qwen и видеогенерацией с освобождением 8 ГБ VRAM.
- Проверка сохранения графики 2.5D Semi-Realistic Anime CGI / Felare на коротких тестовых клипах.

## Правила качества и безопасности
- Реальные тесты на Windows и пользовательских файлах отдельно от mock-тестов.
- Тестируется собственный результат против оригинала; проверка Qwen самой себя не равна независимой валидации.
- Не устанавливать новые модели и не изменять FramePack без фактической проверки совместимости.
- Ни личные фото/видео, ни модели, ни промпты не публикуются в репозитории.
- Источник обновлений защищается правами GitHub; пользователь явно подтверждает установку.
